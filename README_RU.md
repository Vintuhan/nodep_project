# nodep project — Android port

Это Android-версия исходного браузерного фильтра. Платформенная часть перенесена на WebView, а проверка страницы по JavaScript оставлена совместимой с исходной логикой.

## Что уже есть
- браузер внутри приложения;
- проверка домена до загрузки страницы по локальному списку;
- пользовательский список блокировок;
- проверка заголовков, текста и структуры страницы после загрузки;
- предупреждение с таймером и блокировка по кнопке;
- доверие к странице на 24 часа;
- отдельная страница блокировки;
- структура проекта под Android Studio.

## Важное ограничение этого архива
Файлы с исходной базой сайтов/слов НЕ копируются в архив. Это сделано намеренно: они должны оставаться твоими локальными данными.

В распакованной папке старого расширения запусти:

`tools\\IMPORT_EXTENSION_DATA.bat "C:\\путь\\к\\распакованному\\nodep-project"`

Скрипт локально скопирует `data/keywords.js`, `data/whitelist.js` и `data/seed.json` в Android-проект.

## Сборка
Открой папку `nodep-android` в Android Studio и выполни:

**Build → Build APK(s)**

Готовый debug APK будет в:

`app\\build\\outputs\\apk\\debug\\app-debug.apk`

Для release-сборки используй **Build → Generate Signed App Bundle / APK** и создай свой keystore.

## Почему это не системный блокировщик Chrome
Эта версия — отдельный браузер на Android. Обычное Android-приложение не получает API Chrome Extension для перехвата навигации в стороннем Chrome. Для блокировки всех браузеров нужен отдельный системный слой (например, VPN/локальный DNS-фильтр), который здесь специально не включён.
